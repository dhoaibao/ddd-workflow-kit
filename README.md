# Domain-Driven Design Skill Research

This repository is a research and documentation workspace for building a reusable skill that applies Domain-Driven Design (DDD) to any project. It is currently in the research/documentation phase: the material under [`docs/foundation/`](docs/foundation/) establishes a language-neutral foundation, decision points, and adoption practices.
