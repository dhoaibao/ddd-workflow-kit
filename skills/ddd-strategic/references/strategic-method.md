# Lean strategic method

## Select one slice

Confirm outcome, fit, terms, examples, owner, and evidence. Compare boundaries only where they affect the selected increment. Keep later contexts as hypotheses.

## Context boundary

Use coherent language, policy, lifecycle, decision ownership, and consistency needs. Record explicit in/out scope, key terms, scenarios, and owner. Modules, tables, teams, and deployment services are observations, not proof of a domain boundary.

## Relationships

For each touched relationship record upstream/downstream direction, contract/communication, translation responsibility, consistency/failure assumption, and evidence. Avoid mechanical relationship labels.

## Conditional depth

Generate maps, glossary, and additional context files only when a current relationship, classification decision, or language conflict requires them. A single-context slice should not generate unrelated documents.

## Handoff

Tactical work receives exactly one selected context with purpose, boundary, language, scenarios, and invariants to investigate. It receives relationships, owner, assumptions, or open questions only when material to the selected slice; if selection is unsupported, stop for the smallest human decision.
